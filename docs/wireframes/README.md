# Wireframes de referencia (Fase 8.8)

Prints de uma rotina de comunicados usados como inspiracao de estrutura
para o redesign do Clubinho do Libro. Nao sao telas do nosso produto:
servem de referencia de layout, aplicando por cima o design system atual
(liquid glass, paleta oliva/bege).

| Arquivo | O que mostra | Padroes aproveitaveis no clube |
|---------|--------------|--------------------------------|
| `01-lista-comunicados.png` / `02-...-scroll.png` | Lista com busca, botao de filtro, cards com tags, titulo, autor e data; bottom nav com botao central destacado | Feed de atividades: busca/filtro por tipo, cards com tag do tipo de atividade (comentario, capitulo, livro), autor e data; navegacao inferior |
| `03-detalhe-comunicado.png` | Tela de detalhe: voltar no header, autor e data, titulo, imagem, texto e card de acao com CTA | Detalhe de atividade/comentario e pagina do livro (capa, descricao, card de acao "Avaliar livro") |
| `04-detalhe-com-comentario.png` | Mesmo detalhe com campo de comentario fixo no rodape | Comentario do capitulo com input fixo no rodape |
| `05-responder-enquete.png` | Formulario de resposta: pergunta, opcoes tipo radio, Confirmar (primary) e Cancelar (outline) | Fluxo de avaliacao do livro (nota + resenha) e futuros sorteios/votacoes; exemplo claro das variantes de botao (8.5) |
| `06-toast-sucesso.png` | Toast de sucesso com icone e borda verde | Feedback global de sucesso/erro apos acoes (integra com 8.1) |
